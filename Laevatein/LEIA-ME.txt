LAEVATEIN — FUGA DE MARTE
=========================

Laevatein — Fuga de Marte é um jogo de ação e plataformas 2D em pixel art,
executado no navegador. Ajude um astronauta a escapar: atravesse três fases,
derrote inimigos e chefes, recolha as chaves necessárias e embarque na nave.

DESCARREGAR
-----------
Descarregue o jogo em formato ZIP:
https://github.com/larissaRgj/laevatein/raw/refs/heads/main/LaevateinFinal.zip

Extraia o arquivo por completo e mantenha assets/, css/, js/ e index.html na
mesma pasta. Não é necessário instalar pacotes npm para jogar: o bundle do
jogo já está incluído. Recomenda-se iniciar um servidor HTTP local, em vez de
abrir index.html directamente.

FUNCIONALIDADES
---------------
- Três fases com cenários, inimigos e desafios próprios.
- Combate com disparos, saltos e jetpack; também pode derrotar inimigos saltando
  sobre eles.
- Chefes com padrões de ataque distintos e várias formas no confronto final.
- Chaves para desbloquear os chefes, corações para recuperar vidas, pontuação
  e combos.
- Controlos por teclado, gamepad e botões no ecrã táctil.
- Canvas com resolução lógica de 1280 × 720, adaptada ao tamanho da janela.
- Recorde e preferência de som guardados no armazenamento local do navegador.

REQUISITOS
----------
- Navegador moderno com suporte para Canvas, JavaScript ES2020 e áudio HTML5.
- Node.js 18+ para o servidor local incluído; ou Python 3 como alternativa.
- Node.js 18+ e npm para reconstruir o bundle (apenas desenvolvimento).

EXECUTAR NO WINDOWS
-------------------
1. Extraia o ZIP.
2. Abra a pasta Laevatein.
3. Execute Iniciar-Jogo.bat.

O atalho usa Node.js, se estiver instalado; caso contrário, tenta usar Python
através do comando py. Mantenha a janela do servidor aberta enquanto joga.

EXECUTAR COM NODE.JS
--------------------
Abra um terminal na pasta Laevatein e execute:

    node js/local-server.js

Abra o endereço indicado no terminal, normalmente:

    http://127.0.0.1:8765/

Se a porta estiver ocupada, o servidor tenta as portas seguintes. Pare-o com
Ctrl+C.

EXECUTAR COM PYTHON 3
--------------------
Na pasta Laevatein, execute:

    python -m http.server 8765 --bind 127.0.0.1

No Windows, também pode usar:

    py -3 -m http.server 8765 --bind 127.0.0.1

Depois, abra http://127.0.0.1:8765/ e pare o servidor com Ctrl+C.

CLONAR O REPOSITÓRIO
--------------------

    git clone https://github.com/larissaRgj/laevatein.git
    cd laevatein/Laevatein
    node js/local-server.js

Em seguida, abra o endereço indicado no terminal.

CONTROLOS
---------
Mover:                 setas esquerda/direita ou A/D
Saltar:                seta para cima ou W
Jetpack no ar:         manter seta para cima/W ou Shift
Acelerar:              Shift
Disparar:              Espaço, Z, J ou K
Pausar/continuar:      P ou Esc
Som ligado/desligado:  M
Interagir com a nave:  E ou caminhar até à porta

Em dispositivos móveis, use os botões no ecrã e jogue na orientação paisagem.
Também há suporte para gamepads compatíveis com o navegador.

OBJECTIVO
---------
Em cada fase, elimine o número de inimigos indicado e recolha três chaves para
libertar o chefe. Recolha corações para recuperar vidas. Após derrotar o chefe
final, caminhe até à porta da nave para concluir a fuga.

RECONSTRUIR O BUNDLE (OPCIONAL)
-------------------------------
Só é necessário depois de alterar módulos JavaScript dentro de js/:

    npm ci
    npm run build

O comando actualiza js/game.bundle.js. É necessário Node.js 18+ e npm. Inclua
o bundle actualizado no commit.

ESTRUTURA
---------
assets/                 Músicas, sprites, cenários e referências
css/style.css           Estilos, menus e interface responsiva
js/core/                Carregamento de recursos, áudio, entrada e estados
js/entities/             Nave e movimento dos inimigos
js/scenes/               Abertura, menus, fases e lógica do jogo
js/utils/                Animação de sprites
js/main.js               Entrada dos módulos-fonte
js/game.bundle.js        Bundle pronto para o navegador
js/local-server.js       Servidor HTTP local
index.html               Página do jogo
Iniciar-Jogo.bat         Atalho de inicialização para Windows
package.json             Script de build e esbuild
package-lock.json        Dependências bloqueadas

NOTAS DE DESENVOLVIMENTO
------------------------
O projecto não tem actualmente testes automatizados nem comandos de lint.
node_modules/ está presente no histórico do Git; ignorá-lo não remove os
ficheiros já rastreados. A fonte Press Start 2P é carregada do Google Fonts;
sem ligação, o navegador usa uma fonte alternativa.
